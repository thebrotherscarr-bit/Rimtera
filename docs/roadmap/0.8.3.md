# 0.8.3: Hardmode research tiers and hardmode events

**Scope choice (assumption @designer made; owner may overrule):** The owner's recorded calls in `docs/PLAN.md` and `docs/VISION.md` §3.1 state: "Terraria's ladder is the base; research adds time on top. Beating a boss opens the next research tier." The existing code has six tiers ending at `astral` (Astral Assembler). **@designer decision:** 0.8.3 adds **four new hardmode research tiers** (lumenite, voidsteel, astral2, escape) that follow Terraria's ore ladder (lumenite → voidsteel → astral → ship), each opened by its boss and unlocking the next station tier. This is the interpretation of "hardmode research tiers" in the plan row; if the owner intended only Fracture-gating/re-pricing the existing three post-Fracture tiers, the spec will be adjusted at the discussion point.

**Scope:** New hardmode research tiers following Terraria's ore ladder, and hardmode events scheduled by the storyteller with warnings. Both integrate into the post-Fracture run.

---

## 1. Hardmode research tiers (new tiers, new ids)

The existing `ResearchTiers` list ends at `astral` (Astral Assembler). 0.8.3 adds **four new tiers** that gate the upper ore ladder (lumenite → voidsteel → astral → the escape). Each tier is opened by a boss, takes minutes of study at the base rate, and unlocks a station upgrade and the recipes that use its material.

| Id | Name | Opens on boss defeat | Minutes | Unlocks (station/recipe) | Materials (gates recipes using these) | Gives (chronicle line) |
|----|------|---------------------|---------|--------------------------|--------------------------------------|------------------------|
| `lumenite` | Lumenite studies | **WarshipCore** (the last of the Hard Trio) | 6 | `VoidForge` (tier-5 forge) | `LumeniteBar`, `LumeniteOre`, `PrismEssence` | The Void Forge, and recipes using lumenite and prism essence. |
| `voidsteel` | Voidsteel studies | **MutatedFlora** (bulb boss) | 7 | `AstralAssembler` (tier-6 assembler) | `VoidsteelBar`, `VoidsteelOre`, `BlightEssence` | The Astral Assembler, and recipes using voidsteel and blight essence. |
| `astral2` | Astral convergence | **VoidCantor** (ritual boss) | 6 | `StarWeaver` (new: tier-7 weaver for the ship) | `AstralBar`, `AstralOre`, `FlightEssence` | The Star Weaver, and recipes using astral and flight essence. |
| `escape` | Ship systems integration | **AstroGod** (final boss) | 8 | — (no new station; unlocks ship part recipes) | `PrecursorRelic`, `AncientPowerCell`, `VoidEssence` | The ship part recipes and the launch sequence. |

**Pacing check (with @balance):** post-Fracture research was 4 + 5 + 5 = 14 min (essences, flora, astral). New total: 6 + 7 + 6 + 8 = **27 min** at base rate (station AI alone). With one research resident (0.6 sp/s) that's ~16 min; with two ~11 min. Fits the 5.6 h second ladder (research is ~⅓ of post-Fracture time; the rest is exploring, fighting, sieges).

**Save compatibility:** `RestoreColonyResearch` already treats any tier whose boss is defeated as "done" on old saves. New tiers simply won't exist on old saves; defeating their boss on load will open them.

## 2. Hardmode events as storyteller incidents

Current hardmode events (`HardEventUpgrades` in `GameSimulation.Hardmode.cs`) upgrade event rosters 40% after the Fracture, but they still roll on Terraria's dusk schedule. 0.8.3 moves them under the **storyteller** so they come with **warnings**, **categories**, **refire timers**, and **threat-scaled weights**. The storyteller picks which hardmode event the colony's progress allows, same as `InvasionIncident` does for pre-Fracture invasions.

### New incidents (added to `StoryEvents.cs`, registered in `Storyteller` constructor when `FractureActive`)

| Class | Id | DisplayName | Category | RefireHours | CanFire gate | Weight |
|-------|----|-------------|----------|-------------|--------------|--------|
| `HardmodeInvasionIncident` | `hard-invasion` | Hardmode invasion | MajorThreat | 60 | `FractureActive && context.InvasionReady && !context.BossActive` | 1.0 |
| `DarkSunIncident` | `dark-sun` | Dark Sun (solar-flare eclipse) | MajorThreat | 72 | `FractureActive && !teller.SolarFlareActive && context.Act >= 4` | 0.7 |
| `HardmodeRaidIncident` | `hard-raid` | Raider siege (upgraded) | MajorThreat | 36 | `FractureActive && context.ColonistCount >= 3` | 0.9 |
| `HardmodeMoonIncident` | `hard-moon` | Rust Moon (upgraded) | MajorThreat | 48 | `FractureActive && !context.BossActive` | 0.8 |
| `HardmodeWeatherIncident` | `hard-weather` | Acid rain / dust storm (upgraded) | MinorThreat | 30 | `FractureActive && context.Act >= 4` | 0.7 |

**Execution:** each `TryExecute` calls the host to start the corresponding `WorldEventKind` (e.g. `WorldEventKind.DarkSun`, `WorldEventKind.HardScavengerRaid`, `WorldEventKind.HardRustMoon`, `WorldEventKind.HardAcidRain`, `WorldEventKind.HardDustStorm`). The host returns the warning text; the incident logs it and the HUD shows the countdown letter.

**Refire timers:** shorter than pre-Fracture invasions (Terraria's hardmode events are more frequent), scaled by storyteller personality (Chaotic shorter, Builder longer via the existing rest multiplier).

**Act gating:** Act 4 (the Zealots) and later. Act 5 (Collapse) and Act 6 (Launch) raise major-threat weight via the existing `threatBias` and `act` factor in `PickCategory`.

## 3. Dev-console commands (added in this step)

| Command | What it does |
|---------|--------------|
| `research list` | (exists) lists all tiers including the four new ones |
| `research open <tier>` | Opens a tier immediately (sets its boss as defeated) |
| `research done <tier\|all>` | (exists) finishes a tier |
| `research reset <tier\|all>` | (exists) puts a tier back to unstudied |
| `incident hard-invasion` | Forces a hardmode invasion (bypasses gate) |
| `incident dark-sun` | Forces the Dark Sun eclipse |
| `incident hard-raid` | Forces an upgraded raid |
| `incident hard-moon` | Forces an upgraded Rust Moon |
| `incident hard-weather` | Forces upgraded acid rain or dust storm |
| `hardmode stage` | (exists) shows the post-Fracture chain state |

## 5. Acceptance tests (for @qa → self-tests)

1. **ResearchTiersSelfTests**: all 10 tiers (6 old + 4 new) exist in progression order; each `Cost = Minutes * 60`; `FindTier` finds new ids; `ResearchOpen` returns true after the named boss is defeated.
2. **ResearchSaveLoadSelfTests**: a world saved before 0.8.3 loads; defeating WarshipCore, MutatedFlora, VoidCantor, AstroGod on that world opens the corresponding new tier and unlocks recipes.
3. **HardmodeIncidentSelfTests**: each new incident registers in `Storyteller.Incidents` when `FractureActive`; `CanFire` respects gates (act, boss active, colonists); `RefireHours` matches table; `TryExecute` returns non-null warning text when host stubs `ScheduleHardEvent`.
4. **StorytellerCategoryWeightSelfTests**: with `FractureActive` and Act ≥ 4, `PickCategory` includes the new MajorThreat incidents; Chaotic weight > Steady > Builder for major threats.
5. **DevConsoleHardmodeSelfTests**: `incident hard-invasion`, `dark-sun`, `hard-raid`, `hard-moon`, `hard-weather` execute without error and mark `dev.console.used`.
6. **AssetCheckSelfTests**: all new item and station sprites exist at correct size (icons 64 px, stations 96×96); all new sound cues listed by `--sound-cues` have a file (placeholder or real).
7. **PacingSelfTests** (with @balance): post-Fracture research total 27 min base; with 1 resident ~16 min; second ladder 5.6 h still holds in the model (`RunPacing.cs`).
